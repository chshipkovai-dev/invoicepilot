## Суть за 30 секунд

**Что:** Веб-приложение — AI агент который пишет follow-up письма за фрилансера когда клиент не платит вовремя

**Для кого:** Фрилансеры (дизайнеры, разработчики, копирайтеры, консультанты) которые работают с несколькими клиентами

**Боль:** Фрилансеры теряют 2+ часа/неделю на "ну когда же ты заплатишь?" письма. И $10k в год на инвойсах которые так и не оплатили.

**Решение:** Вводишь данные инвойса → AI генерирует серию писем (дружелюбное → настойчивое → формальное) → ты копируешь и отправляешь или нажимаешь одну кнопку

**Цена:** $39/мес

**Path to $1k MRR:** 26 клиентов

---

## Ключевое решение по продукту

**Агент НЕ отправляет письма сам** — он пишет черновик, ты нажимаешь "отправить".

Почему это важно:
- Фрилансеры боятся что AI испортит отношения с клиентом
- "AI пишет, я отправляю" = 90% экономии времени + 100% контроль
- Легче продавать ("это как умный помощник, не робот")

---

## Как работает продукт

```
1. Регистрируешься на payagent.com
2. Добавляешь инвойс:
   - Имя клиента
   - Email клиента
   - Сумма ($)
   - Дата выставления
   - Краткое описание работы
3. AI генерирует 3 письма:
   - День 3 просрочки: дружелюбное напоминание
   - День 7: настойчивое, упоминает сумму
   - День 14: формальное, намекает на последствия
4. Ты видишь все три — копируешь нужное в Gmail
5. Отмечаешь инвойс как оплаченный когда деньги пришли
```

## Технический стек

| Слой | Технология | Зачем |
|------|-----------|-------|
| Frontend + Backend | Next.js 14 | Один проект, деплой на Vercel |
| БД + Auth | Supabase | Бесплатно, безопасно из коробки |
| AI | Claude API (Haiku) | Дёшево ($0.25/M токенов) для писем |
| Оплата | Stripe | Стандарт индустрии |
| Хостинг | Vercel | Бесплатно для старта |
| Email уведомления | Resend | Бесплатно до 3000/мес |

**Стоимость инфраструктуры до $1k MRR:** ~$15-20/мес
