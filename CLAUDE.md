# InvoicePilot (Freelance Payment Agent)

## Что это
AI агент для автоматизации выставления счетов и отслеживания платежей для фрилансеров.

## Stack
- Next.js 14, TypeScript, Tailwind
- Supabase (auth + database)
- Stripe (payments)
- App dir: `app/`

## Статус
MVP готов. Без активного продвижения. Заморожен.

## Не трогать
- `app/api/` — API роуты
- Stripe webhook handlers
